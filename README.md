# Medical Appointment Platform

## Présentation

Medical Appointment Platform est une plateforme de prise de rendez-vous médicaux destinée à faciliter la mise en relation entre les patients et les médecins d'un centre médical.

## Objectifs

- Rechercher un médecin selon sa spécialité.
- Consulter les disponibilités des médecins.
- Réserver et annuler des rendez-vous.
- Gérer les disponibilités.
- Administrer les comptes, les médecins, les spécialités et les cabinets.

## Cas d'utilisation

- **UC1 :** Rechercher un médecin et consulter ses disponibilités.
- **UC2 :** Réserver un rendez-vous médical.
- **UC3 :** Annuler un rendez-vous médical.
- **UC4 :** Gérer les disponibilités.
- **UC5 :** Gérer les comptes, médecins, spécialités et cabinets.

## Organisation du dépôt

- `backend/` : logique métier et API.
- `frontend/` : interface utilisateur.
- `docs/` : fiches UC, diagrammes UML et documentation de l'architecture.
- `tests/` : tests du projet, selon l'organisation retenue.
